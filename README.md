# FORM Golf

The repository is being migrated from a monolithic HTML prototype to a split application structure:

- `index.html` — application markup
- `assets/form-base.css` — core styling
- `assets/form-responsive.css` — responsive styling
- `assets/catalog-data.js` — equipment catalog snapshot
- `assets/app-1.js`, `assets/app-2.js`, `assets/app-3.js` — fitting, profile, and result logic

The current production page remains intact until the full split build is transferred and verified.
